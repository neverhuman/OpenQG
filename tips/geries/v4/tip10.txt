# 3. The new primitive: Minimal Anomaly–CP Closure

MACC-LS begins with a minimal local chiral gauge law:

[

[

\quad
\text{mixed gravitational anomaly}=0,
\quad
\text{Witten }SU(2)\text{ anomaly}=0,

plus Yukawa admissibility and minimality.

Gauge-invariant Yukawa slots require:

[
Y_u=-Y_Q-Y_H,\qquad
Y_d=-Y_Q+Y_H,

[
Y_e=-Y_L+Y_H,\qquad
Y_N=-Y_L-Y_H=0.

So:

[
Y_L=-Y_H.
]

The (SU(2)^2U(1)) anomaly gives:

[
N_cY_Q+Y_L=0,

hence:

[
Y_Q=\frac{Y_H}{N_c}.

Normalize electric charge by (Q_{\rm em}=T_3+Y) and (Y_H=\frac12). Then:

[
Y_Q=\frac{1}{2N_c},

[
Y_u=-\frac{N_c+1}{2N_c},
\qquad
Y_d=\frac{N_c-1}{2N_c},

[
Y_L=-\frac12,\qquad
Y_e=1,\qquad
Y_N=0.
]

The remaining local anomalies cancel identically:

[
[SU(N_c)]^2U(1):\quad 2Y_Q+Y_u+Y_d=0,

[
[\mathrm{grav}]^2U(1):\quad
2N_cY_Q+N_cY_u+N_cY_d+2Y_L+Y_e+Y_N=0,

[
[U(1)]^3:\quad
2N_cY_Q^3+N_cY_u^3+N_cY_d^3+2Y_L^3+Y_e^3+Y_N^3=0.

The Witten global (SU(2)) anomaly requires the number of left-handed weak doublets to be even. Per generation that number is:

[

Therefore:

[

N_c\ \text{odd}.

A nonabelian color factor requires (N_c>1). Minimality then gives:

\boxed{N_c=3}.

Substituting (N_c=3) gives:

Y_u=-\frac23,\quad
Y_d=\frac13,\quad
Y_L=-\frac12,\quad
Y_e=1,\quad
Y_N=0.

[
\boxed{
SU(3)_c,\quad SU(2)_L,\quad U(1)_Y,\quad
N_c=3,\quad
\text{hypercharge quantization},\quad
\text{chiral weak structure},\quad
\text{one-family anomaly cancellation}

]

and the global group becomes:

[
\boxed{
G_{\rm SM}=
\frac{SU(3)_c\times SU(2)_L\times U(1)_Y}{\mathbb Z_6}.
}
]

This is a real improvement over the tips: the (M_3(\mathbb C)) color block is no longer just assumed; it is the minimal odd nonabelian color closure compatible with local and global anomalies.

The uploaded tips repeatedly admitted that “three generations” was not solved. MACC-LS supplies a conditional theorem:

For (N_g) generations, the number of physical CP-violating phases in a quark mixing matrix is:

[
\frac{(N_g-1)(N_g-2)}{2}.
]

For (N_g=1), this is zero. For (N_g=2), this is zero. The first value admitting an intrinsic CP-odd weak invariant is:

[
N_g=3.

Equivalently, a Jarlskog-type invariant requires a nonzero commutator structure:

[
\operatorname{Im}\det\left[
Y_uY_u^\dagger,,
Y_dY_d^\dagger

]

which is impossible for fewer than three nondegenerate generations.

MACC-LS adds one primitive:

> A viable low-energy chiral matter law must be minimally capable of CP-odd history without adding new light gauge representations.

That is weaker than deriving the baryon asymmetry, but stronger than merely asserting “index = 3.” It gives:

[
\boxed{N_g=3}

as the minimal flavor replication count compatible with intrinsic weak-sector CP history.

This does **not** derive CKM angles, PMNS angles, neutrino masses, or the baryon asymmetry. It only derives the structural integer (N_g=3) under the stated closure condition. That is why I raise the score, but not above 90.

# 6. The law/state theorem

This is the second major compression.

Let an observable row be:

[
r = E(L,s,\chi),
]

where (L) is the universal law, (s) is the historical/source/initial state, and (\chi) is the extraction convention.

If there exist two admissible states (s_1,s_2) such that:

[
E(L,s_1,\chi)\neq E(L,s_2,\chi),
]

then (L) alone does not predict (r). Any adapter emitting a value for (r) must either:

1. derive (s) from (L);
2. receive (s) from a non-target independent state pack;
3. declare a free state parameter; or
4. leak the fixture/source value.

Only the first two can support a strict OpenQG `predicted` row.

This theorem explains why so many fixture families must be refused. GWOSC event masses, EHT angular sizes, SPARC rotation points, JPL orbital elements, Pantheon supernova moduli, and many BAO/CMB summaries are not pure law rows. They are law-plus-state rows. A law can provide evolution equations; it cannot infer the historical catalog entry without a state derivation.
