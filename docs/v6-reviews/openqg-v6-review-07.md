# Survivor audit: ndgp-proposed-fixed-rc

`ndgp-proposed-fixed-rc` is not a genuine candidate worth external human attention. It is a useful oracle-regression specimen. The phrase I would use is: the least-dead body in the morgue, not a live modified-cosmology lead.

The stored artifact is `run-data/v6-chunk-6-white-paper.json`. It records generation 25, parent `g0001-proposer`, final V6 score 60.0, and a scorecard with 20 derivation, 0 data fit, 0 novelty, 15 unification, 13 robustness, and 12 parsimony. The data fit is explicitly negative: `delta_lnz = -1.6893933854942986`, `delta_aic = 3.3787867709885973`, `likelihood_mode = covariance`, `covariance_block_count = 6`. On admitted data, the candidate does not beat LambdaCDM. It survives because the rubric gives large non-data credit.

The physics content is thin. The theory has baseline background values: `h = 0.674`, `omega_m = 0.315`, `w0 = -1`, `wa = 0`, `sigma8 = 0.811`, `mg_family = none`, and `ndgp_omega_rc = 0` in the serialized background. It has a derived parameter `geff_over_g = 1.1666666666666667` certified by `relation: ndgp_geff_over_g` with input `beta = 2.0`. During scoring, `crates/openqg-core/src/theory/binding.rs::bind_modified_background` inverts that certificate and binds `ndgp_omega_rc = 0.7097028068896183`, setting the background to the nDGP family for prediction.

The contradiction is structural. The theory terms in the run data are only `einstein_hilbert` and `cosmological_constant`. There is no brane-bending scalar, no crossover-scale term, no DGP brane/bulk action marker. `crates/openqg-core/src/theory/sectors/ndgp.rs` contains an actual nDGP response implementation, but `vetoes.rs::adjudicate` does not require a corresponding term when a certificate binds nDGP. The current `StructurallyUngenerated` check covers dynamic dark energy and alpha-basis deviations by substring, not derived nDGP or f(R) sectors. If V6.1 disqualifies drifted dials without terms, it should also reject a bound nDGP dial without a term.

The growth direction is also wrong for the admitted tensions. The nDGP normal branch enhances growth. `sectors/ndgp.rs` says this explicitly, and the tests assert `normal_branch_enhances_gravity`. The data brief logic in `crates/openqg-bench/src/zyal_genome/proposer_memory.rs::build_data_brief` tells the proposer that growth pulls are negative and growth must be suppressed. The survivor's data-fit score of zero reflects this: it is a derivation-rich but observationally unhelpful proposal.

The claimed V6.1 rescore at 25.0 is not reproducible from the included run data. The archive includes only three white-paper JSON files under `run-data/`, not the full 754-call proposal ledger or the data fixtures referenced by the acceptance docs. The prompt says the V6.1 rescore is the claim to verify; the stored scorecard still says 60.0. I can infer how 25.0 might arise if V7 removed unification, robustness, or parsimony credit, but that is not recorded as an artifact. This should be treated as a release-blocking audit gap.

What would sharply test it? A single addition: a profile-fitted nDGP model-class registry comparison against the same growth and distance data, with LambdaCDM allowed to fit `h`, `omega_m`, and `sigma8`. The code already has `crates/openqg-core/src/theory/league.rs::ModelClass::ndgp` and `model_league`. Use that path, not the fixed proposal scorecard. The test should report whether nDGP normal branch, with `ndgp_omega_rc` free and `sigma8` free, improves BIC or Laplace evidence over `ModelClass::lcdm_growth`. My expectation is no, because nDGP enhances growth while the observed S8/fsigma8 pulls prefer suppression.

Minimum V7 survivor requirements: add an `ndgp_brane` or equivalent term grammar requirement in `vetoes.rs`, require quantified Vainshtein/screening if the linear coupling is nonzero, and require `model_league` evidence over the relevant model class. A candidate that earns 20 derivation points but has negative data evidence and no novel out-of-fit witness should not be called "honest candidate"; it should be called "structurally incomplete, data-disfavored derivation fixture."

If the team wants to keep it, keep it as a regression fixture: "certified nDGP binding must affect growth; normal branch must enhance growth; missing brane term must kill; data fit must remain non-positive on current growth tensions." That is valuable. It is not a lead for cosmologists.
