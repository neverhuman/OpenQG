[

# The missing conceptual compression

## Law–State–Semantics factorization

The archive already noticed the law/state split, but it did not compress the benchmark problem far enough. The missing third factor is **observable semantics**.

A strict OpenQG prediction must factor as:

[
P_r = E_r(L, C, S_r)
]

where:

* (r) is the requested benchmark row.
* (L) is the law: field equations, symmetry principles, action, constraints.
* (C) is the constants ledger: structural integers, derived dimensionless constants, metrology anchors, and any remaining free parameters.
* (S_r) is the independent state package relevant to row (r): initial conditions, boundary conditions, source data, detector state, galaxy state, cosmological state, or material composition.
* (E_r) is the row-specific extraction map: the rule that says which theoretical quantity corresponds to the row’s `observable_id`, unit, uncertainty model, and comparison semantics.

A row is legally predictable only when all four pieces are independently available:

[
\operatorname{Predictable}(r)
\Longleftrightarrow
L\ \text{derived}
\wedge C_r\ \text{derived or irrelevant}
\wedge S_r\ \text{derived or irrelevant}
\wedge E_r\ \text{unambiguous}
\wedge \text{no target leakage}.
]

This is the real compression. It explains why exact null symmetry rows are special. For a null Lorentz-violation coefficient, WEP-violation parameter, or GR-deviation parameter, the state dependence cancels because the law says the forbidden coefficient is identically zero in the declared domain. For most other rows, the row value is not determined by law alone.

## The no-free-state theorem

**Theorem.**
Let two admissible worlds (U) and (U') share the same law (L), derived constants (C), and row metadata (m_r), but differ in allowed state (S_r) such that:

[
E_r(L,C,S_r) \neq E_r(L,C,S'_r).
]

Any fixture-independent adapter (A(L,C,m_r)) that does not receive (S_r), does not derive (S_r), and does not leak the target fixture value must output the same value in both worlds. Therefore it is wrong in at least one world. Hence no law-only adapter can validly predict that row.

**Consequence.**
Rows from GW event catalogs, EHT images, planetary ephemerides, galaxy rotation curves, atomic transition experiments, supernova compilations, BAO surveys, CMB parameter fits, particle mass tables, and neutrino global fits are not law-only predictions. They require either:

1. a derivation of the relevant source state from deeper principles,
2. an independent source-state pack with provenance,
3. or refusal.

This theorem is not a physical theory of alpha or flavor. But it is a benchmark-honest impossibility result. It proves why broad row coverage without independent state data is usually leakage, hidden fitting, or semantic confusion.

The same theorem has a semantic version:

**Semantic identifiability rule.**
If row metadata does not uniquely specify the observable extraction map (E_r), then no numeric prediction is defined, even if the theory has a related equation. This is especially important for rows that might be bounds, residuals, normalized templates, fitted parameters, catalog labels, or source-conditioned observables.

That rule matters for `sme_*`: predicting a Lorentz/CPT coefficient as exactly zero is valid only if the row represents the coefficient, a coefficient-like residual, or a comparison that accepts a zero coefficient. If the row is merely an experimental upper bound, a publication-level constraint, or a non-coefficient statistic, the adapter must refuse. The SME itself is an effective-field-theory framework whose Lorentz/CPT-violating operators are controlled by coefficients constrained by experiments, so row semantics are essential. ([arXiv][3])

# What previous agents assumed too quickly

The prior tips were strongest where they enforced refusal. They were weakest where they quietly counted formal structure as prediction.

The most important over-assumptions were these:

1. **Finite algebra selection was treated as a derivation.**
   The algebra ( \mathbb{C}\oplus\mathbb{H}\oplus M_3(\mathbb{C}) ) is powerful and highly compressive, but the archive does not prove it is uniquely forced among all possible internal algebras by a fixture-independent theorem.

2. **Yukawas were treated as if they came from geometry.**
   In the spectral triple, the finite Dirac operator can encode Yukawa matrices. Encoding is not derivation. Without a principle fixing (D_F), the masses, CKM angles, PMNS angles, and neutrino sector remain free or unsupported.

3. **Asymptotic safety was treated as a constants engine.**
   A fixed point can reduce parameter freedom only after the complete matter-gravity beta system, relevant directions, matching scales, thresholds, and scheme-independent observables are controlled. The archive does not contain that calculation.

4. **Dimensional transmutation was treated as a QCD prediction.**
   (\Lambda_{\rm QCD}) follows from a UV value of (g_3), thresholds, and renormalization convention. Without deriving those, the QCD scale is not predicted.

5. **Cosmological equations were mistaken for cosmological rows.**
   Friedmann equations do not predict (\Omega_b), (\Omega_c), (H_0), (n_s), (A_s), (\tau), dark matter abundance, or vacuum energy without state and parameter inputs. Planck, DESI, and Pantheon-like surfaces are empirical parameter-estimation pipelines, not law-only consequences. ([arXiv][4])

6. **CODATA and PDG values were sometimes treated as theory outputs.**
   CODATA values are adjusted recommended constants derived from experimental/theoretical input data, and PDG values are evaluated compilations of measurements and analyses. They are not fixture-independent predictions just because a theory uses the same symbols. ([NIST][5])

7. **Source catalog rows were under-gated.**
   EHT, SPARC, GWOSC, Horizons, atomic spectra, and similar rows all require source-specific state packs and extraction maps. EHT’s M87* result, for example, depends on source-specific imaging, angular scale, distance/mass inference, and GRMHD modeling, not merely on the existence of GR. ([arXiv][6]) SPARC is explicitly a database of individual galaxies with photometry and rotation curves, so its rows are state-conditioned by construction. ([Astrophysics Data System][7])

* `observable_id`,
* declared family/prefix,
* public row metadata,
* unit,
* declared observable description,
* shape information sufficient to identify whether the row is a null coefficient, deviation, bound, source-conditioned quantity, or metrology value.

The gate predicate is:

[
\mathcal{G}(r)=1

only if:

1. the row belongs to one of the accepted null families,
2. the row semantics identify a coefficient/deviation whose theoretical value is exactly zero,
3. the unit is compatible,
4. no source-state data are required,
5. no missing constant is required,
6. the output is independent of fixture target values.

Otherwise:

[
\mathcal{G}(r)=0.
]

Then:

[
P_r =
\begin{cases}
0 \pm 0, & \mathcal{G}(r)=1,[4pt]
\texttt{not_implemented}, & \mathcal{G}(r)=0.

]

This is intentionally austere. It prevents the most common failure mode in the archive: emitting measured values under theoretical names.
