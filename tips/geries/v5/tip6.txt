## 3. The missing compression

ARC-MCC uses two primitives.

### Primitive A: Admissible row closure

For each fixture row (i), define:

[
\widehat y_i =
E_i!\left(
R_i!\left[
\Phi_{\mathcal L,\theta}(s_i)
\right]
\right)
]

where:

[
\mathcal L = \text{law kernel},\quad
\theta = \text{derived constants / free constants / RG trajectory data},
]
[
s_i = \text{source, boundary, initial, or vacuum state},\quad
R_i = \text{physical reduction map},\quad
E_i = \text{source-specific estimator/pipeline}.
]

A strict prediction is allowed only if the proof ledger contains:

[
P_i =
P_{\rm law}
\land P_{\theta}
\land P_{\rm state}
\land P_{\rm estimator}
\land P_{\rm units}
\land P_{\rm uncertainty}.
]

If any factor is missing, the adapter must emit `not_implemented` or `invalid_domain`.

This is the sharpened version of law/state gating: many OpenQG rows are not just law-plus-state; they are **law-plus-state-plus-estimator** rows.

### Primitive B: Minimal chiral core

Instead of assuming the Standard Model internal structure, ARC-MCC starts from the minimal chiral seed class:

[
G_N = SU(N)_c \times SU(2)_L \times U(1)_Y
]

with one electroweak chiral family:

[
Q_L:(N,2)*{Y_Q},\quad
u^c:(\bar N,1)*{Y_u},\quad
d^c:(\bar N,1)_{Y_d},
]

[
L_L:(1,2)*{Y_L},\quad
e^c:(1,1)*{Y_e},\quad
\nu^c:(1,1)_0.
]

Local anomaly cancellation gives:

[
[SU(N)]^2U(1):\quad 2Y_Q+Y_u+Y_d=0,
]

[
[SU(2)]^2U(1):\quad NY_Q+Y_L=0,
]

[
[\mathrm{grav}]^2U(1):\quad
2NY_Q+NY_u+NY_d+2Y_L+Y_e=0,
]

[
[U(1)]^3:\quad
2NY_Q^3+NY_u^3+NY_d^3+2Y_L^3+Y_e^3=0.
]

With a single Higgs doublet normalized by (Y_H=1/2) and gauge-invariant Yukawa couplings, the unique solution up to (U(1)) normalization is:

[
Y_Q=\frac{1}{2N},\quad
Y_L=-\frac12,
]

[
Y_u=-\frac{N+1}{2N},\quad
Y_d=\frac{N-1}{2N},\quad
Y_e=1,\quad
Y_\nu=0.
]

Then:

[
Q_{\rm em}=T_3+Y,
]

so:

[
Q_u=\frac{N+1}{2N},\quad
Q_d=\frac{1-N}{2N},\quad
Q_e=-1,\quad
Q_\nu=0.
]

The Witten (SU(2)) global anomaly requires an even number of left-handed (SU(2)) doublets. With (N) colored quark doublets plus one lepton doublet, the count is (N+1), so consistency requires (N) odd. Known arbitrary-(N_c) Standard Model analyses reach the same point: Witten anomaly cancellation requires (N_c) odd, while triangle anomalies fix the (N_c)-dependent quark charges. ([arXiv][1])

ARC-MCC adds the explicit minimality condition:

[
\boxed{
N_c=\min{N>1:\ N\text{ is nonabelian and Witten-consistent}}=3.
}
]

Therefore:

[
\boxed{
N_c=3,\quad
Y_Q=\frac16,\quad
Y_u=-\frac23,\quad
Y_d=\frac13,\quad
Y_L=-\frac12,\quad
Y_e=1
}
]

and:

[
\boxed{
Q_u=\frac23,\quad
Q_d=-\frac13,\quad
Q_e=-1,\quad
Q_\nu=0.
}
]

This is ARC-MCC’s real physical gain. It derives the color count and charge ratios **inside a declared seed class**. It does not derive (\alpha), particle masses, CKM angles, PMNS angles, or QCD scales.

## 9. Adapter policy

The adapter is a proof checker, not a formula picker.

For each observable:

1. Read `observable_id`, `domain`, `source_dataset_id`, `unit`, and row metadata.
2. Classify the row type: `law_null`, `structural_integer`, `law_plus_state`, `law_plus_state_plus_estimator`, `metrology_anchor`, or `unsupported_dimensionless_constant`.
3. Emit `predicted` only if the proof ledger has all required closure factors.
4. For `ligogr_*`, `microscope_*`, and `sme_*`, require shape validation before emitting zero.
5. For every other row, emit `not_implemented` with `metadata.missing_dependency`.
6. Never use observed row value, source fixture lock, benchmark score, validation row, or reference predictor as input.
7. Preserve row-order independence.

## 10. Falsifiers

1. A clean WEP/Eötvös experiment establishes (\eta_{AB}\neq0) for ordinary neutral matter without an allowed fifth-force/state-sector extension.
2. A fundamental Lorentz/CPT-violating SME coefficient is established as nonzero.
3. A true GR-deviation row—not a source-state catalog row—requires a nonzero beyond-GR parameter in ARC-MCC’s declared IR regime.
4. Low-energy color is shown not to be (SU(3)), or the quark/lepton charge ratios violate the minimal chiral-closure result.
5. The adapter emits (\alpha), masses, CKM/PMNS entries, cosmological parameters, EHT diameters, SPARC velocities, JPL elements, or GWOSC event quantities without a complete independent law/state/estimator proof.
6. A reviewer finds that the (N_c=3) derivation smuggles in measured charge values rather than using only anomaly, Yukawa closure, (U(1)) normalization, and minimality.
