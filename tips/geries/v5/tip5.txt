# 5. The new physics module: minimal chiral closure

[
N_cq+\ell=0

[

Normalize electromagnetism by (h=\frac12). Then:

[

# 12. Adapter policy

```text
observable_id
domain
unit
non-value row description / shape metadata
source family prefix
```

It must not inspect or branch on:

```text
target value
target uncertainty
validation row value
benchmark score
reference predictor output
source fixture lock as calibration
row order
```

Decision rule:

[
\Pi(r)=
\begin{cases}
\texttt{predicted}, & r \text{ is shape-validated law-null or structurally closed} \
\texttt{not_implemented}, & r \text{ is in scope but lacks constants/state/estimator closure} \
\texttt{invalid_domain}, & r \text{ is outside declared theory domain}
\end{cases}
]

The adapter should emit exactly one row per input observable.
