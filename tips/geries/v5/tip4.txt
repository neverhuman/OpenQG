# 1. What the problem is really asking

The brief is not asking for a beautiful “theory of everything” essay. It is asking for an **OpenQG-compliant derivation artifact**.

A row may be marked `predicted` only when an auditor can reconstruct:

```json
{
  "value": "...",
  "uncertainty": "...",
  "unit": "...",
  "provenance": "...",
  "free_parameters_used": [],
  "calibration_data_used": [],
  "metadata.no_calibration_data_used": true
}
```

from theory alone, or from theory plus independently certified non-target state data. A row is not predicted merely because the theory has a related equation.

The central hidden issue is that OpenQG rows are typed. Some are law-null rows. Some are structural rows. Some are constants. Some are source-state rows. Some are estimator-pipeline summaries. Treating all of them as “physics constants” is the main failure mode.

# 2. Where the archive is strong

The archive’s strongest contribution is the **refusal discipline**. It correctly recognizes that a partial strict theory can be scientifically honest even if its official strict `openqg_score` remains near zero.

The safe current row families are narrow:

```text
ligogr_*       -> 0, only for GR-deviation/null-test rows
microscope_*   -> 0, for WEP/Eötvös rows
sme_*          -> 0, only for Lorentz/CPT coefficient or coefficient-null rows
everything else -> not_implemented unless independently closed
```

That is defensible. MICROSCOPE was designed to test the Weak Equivalence Principle using the Eötvös ratio at about the (10^{-15}) precision scale, so a universal-metric law can emit the exact-null value (\eta=0) for a true WEP-violation row without using the measured value as calibration. ([arXiv][1]) The LIGO/Virgo/KAGRA tests-of-GR surface is a deviation/null-test surface, not a source-state catalog; a GR-limit theory can emit zero only for the deviation variables, not for GWOSC masses or spins. ([APS Link][2]) The SME tables are about coefficients for Lorentz/CPT violation, so exact Lorentz/CPT symmetry predicts zero coefficients, but not the published experimental upper bounds themselves. ([arXiv][3])

The archive is also right to keep spectral/noncommutative geometry as a useful scaffold rather than a magic constants engine. The spectral action literature gives a real route from noncommutative spectral data to a Standard Model action coupled to gravity, but using that route does not by itself derive (\alpha), Yukawa matrices, CKM, PMNS, (\Lambda_{\rm QCD}), dark matter abundance, or vacuum energy. ([arXiv][4])

# 3. Where the archive is weak

The repeated weakness is **score inflation by formalism**.

Writing

[
\mu \frac{dg_i}{d\mu}=\beta_i(g)
]

does not derive (\alpha), (g_1,g_2,g_3), or (\Lambda_{\rm QCD}). It only gives a flow once boundary conditions, thresholds, schemes, and relevant directions are fixed.

Writing

[
m_f = y_f v/\sqrt2
]

does not derive masses. It maps already-known Yukawas and (v) into masses.

Writing

[
V_{\rm CKM}=U_u^\dagger U_d
]

does not derive CKM angles. It defines the mixing matrix after the Yukawa matrices are known.

Writing Friedmann equations does not derive Planck, DESI, BOSS, or Pantheon rows. It leaves (\Omega_i), (H_0), (A_s), (n_s), (r), (\rho_\Lambda), reheating, sound horizon, and estimator choices unresolved.

Writing a Kerr shadow formula does not derive an EHT angular diameter. It needs (M), distance, spin, inclination, plasma/emission state, imaging estimator, and uncertainty propagation.

The later tips that score 91–92 are useful as **architecture proposals**, but they cross the line if interpreted as a 90+ physical theory. They add a proof/compiler layer, not a derived hard numerical sector.

[
\mathcal F_r =
{(\theta,S_r,\Pi_r,U_r):
\text{all inputs are compatible with the submitted theory and allowed non-target provenance}}.

Then:

[
\boxed{

\operatorname{diam}

If the row value varies over unresolved constants, source states, estimator choices, or hidden boundary data, then a single numeric output would require an extra selector. If that selector is not derived independently, the row must be `not_implemented`.

# 8. Conditional generation-count result

The best generation-count result is conditional, not absolute.

For (N_g) generations, the number of physical CKM-type CP phases is:

[

Thus (N_g=1) and (N_g=2) have no intrinsic CKM-type CP phase; (N_g=3) is the first value with one irreducible phase. Standard CKM parameter counting gives one complex phase for three generations. ([nikhef.nl][6])

But this is **not** a derivation of CKM angles, the CKM phase value, PMNS, neutrino masses, or baryogenesis. It is a structural minimality theorem.

# 12. Adapter policy

The adapter has four jobs:

```text
1. Classify row type.
2. Build dependency DAG.
3. Prove closure and no-taint.
4. Emit predicted only if the proof passes; otherwise emit refusal.
```

Allowed row types:

```text
law_null            -> exact zero if law symmetry applies
structural_integer  -> only if fixture asks for structural quantity
law_constant        -> only if a constants solver derives it
state_conditional   -> only with independent state pack
observer_pipeline   -> only with fixed estimator pack
metrology_anchor    -> metadata only, not unification credit
bound_comparison    -> predict underlying coefficient, not copied bound
```

The taint checker must fail a row if any dependency path touches:

```text
fixture value
validation value
benchmark score
reference predictor output
source row copied as prediction
post-hoc fitted coefficient
hidden prior selected to improve score
row order or holdout feedback
```
