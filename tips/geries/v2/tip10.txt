## What the brief is really trying to enforce

The brief is an anti-cheating contract. It says a theory must emit one row per observable, but may only mark a row `predicted` when the number comes from a fixture-independent derivation. Unsupported rows must be `not_implemented` or `invalid_domain`. It explicitly forbids fixture copying, reference-predictor reuse, empirical surrogates, neural regressors, hidden free parameters, benchmark tuning, or calling measured constants “derived.”

That changes the optimal strategy. The strongest submission is not the one that fills the most rows. The strongest submission is the one that can survive audit.

The physical literature supports the broad architecture the best attempts converge on: spectral/noncommutative geometry is a serious route for deriving Standard Model gauge/matter structure coupled to gravity; Chamseddine, Connes, and Marcolli present an effective noncommutative-geometry theory of the Standard Model with neutrino mixing and gravity. ([arXiv][6]) Asymptotic safety remains a serious quantum-gravity/matter UV-completion program, but current reviews still treat full gravity-plus-matter predictivity as an active research frontier, not a closed derivation of all low-energy constants. ([arXiv][7])

## Cross-cutting strengths

The strongest files all learned the main lesson: **do not fake numeric coverage**. They correctly keep the immediate strict predictions to law-level null families:

[
\texttt{ligogr_*},\quad \texttt{microscope_*},\quad \texttt{sme_*}
]

with exact values derived from the IR GR/WEP/Lorentz-CPT limit:

[
\Delta_{\rm GR}=0,\qquad \eta_{\rm WEP}=0,\qquad c_{\rm SME}=0.
]

That is the right move. MICROSCOPE’s final WEP result is itself a null test at the (10^{-15}) Eötvös-ratio scale, so a metric low-energy theory can legitimately predict the zero-theory-deviation value while comparing against experimental uncertainty. ([arXiv][8]) Recent LVK tests of GR continue to use compact-binary gravitational-wave events as strong-field tests, so law-level GR-null rows are a legitimate target, while catalog masses and source properties remain state data rather than first-principles law predictions. ([arXiv][9])

They also mostly understand that the benchmark contains many **catalog/state observables**. A universal law does not derive a specific GW event mass, a specific SPARC galaxy rotation point, an EHT angular diameter, a JPL orbital element, or a Pantheon+ supernova distance modulus without initial conditions, source-state data, and observational modeling. EHT’s M87 result, for example, reports a measured crescent diameter of (42\pm3) microarcseconds; predicting that honestly requires independent black-hole mass/distance/spin/emission inputs, not the angular-size fixture itself. ([Astrophysics Data System][10]) SPARC similarly contains 175 late-type galaxies with photometry and rotation curves; a law alone cannot infer each galaxy’s baryonic distribution and formation history without a state ledger. ([Astroweb][11])

## Cross-cutting weaknesses

The biggest weakness is that several attempts self-score 87–88 while admitting that `α`, Yukawa matrices, CKM, PMNS, (m_p/m_e), vacuum energy, baryon asymmetry, dark matter abundance, primordial parameters, and most particle/cosmology/atomic rows are not numerically derived. That is acceptable if these are marked unsupported, but it should cap “mathematical derivation completeness” more strongly than some attempts admit.

The second weakness is **source provenance**. The brief says named literature or admitted local source-pack provenance must justify each rule. Several candidates invent a “trace anomaly selector,” “torsion vacuum selector,” “orbifold selector,” or “generation index” and then score it almost as if it were established. Those ideas can be included as hypotheses, but they should cost points until they have formal derivations or source-pack status.

The third weakness is **observable-shape gating**. The `sme_*` rows are only safe if the fixture row represents a coefficient value/deviation. If the row represents an experimental upper-bound magnitude, the theory value (0) is not automatically the target value; the row should be `not_implemented` or handled as “satisfies bound,” not predicted as the bound itself. The same issue applies to CODATA: NIST/CODATA recommended constants are a least-squares recommended set; exact SI anchors are different from dimensionless targets like (\alpha), which cannot be “predicted” by copying CODATA. ([NIST][12])

The fourth weakness is lack of executable proof. None of these attempts had the full OpenQG repo, fixture tree, and `rtk` environment available, so none actually ran `rtk just fast`, `rtk just universal-micro`, or `rtk just universal-mini`. That does not invalidate the dossiers, but it means all strict scores are projected, not measured.

### `sme_*`

Emit `predicted` only if the row shape is a Lorentz/CPT-violating coefficient value/deviation:

[
a_\mu=b_\mu=c_{\mu\nu}=d_{\mu\nu}=H_{\mu\nu}=\cdots=0.
]

If the row is an experimental **upper-bound magnitude**, do **not** predict the bound itself. Emit `not_implemented` with a note that the theory satisfies the bound but does not predict the experimental sensitivity.

### `eht_*`

Do **not** emit numeric EHT rows by default.

A Kerr shadow formula can be documented:

[
\theta_{\rm sh}
===============

\frac{2R_{\rm sh}(a_*,i)GM}{c^2D_A},
]

but this requires independent (M,D_A,a_*,i) and emission-model assumptions. Without a non-target state ledger, `eht_*` is `not_implemented`.

### `gwosc_*`, `horizons_*`, `sparc_*`

Default `not_implemented`.

These are state/catalog rows. The laws of GR and dynamics can define evolution equations, but event masses, orbital elements, and galaxy rotation points require independent source-state inputs.

### `codata_*`, `pdg_*`, `hepdata_*`, `nufit_*`, `planck_*`, `desi_*`, `boss_*`, `pantheon_*`, `asd_*`

Default `not_implemented`, except:

* exact SI anchors only if row metadata proves the observable is an SI-defining constant;
* representation-only particle rows only if the row is explicitly charge/spin/representation structure, not measured mass/width/lifetime;
* scalaron/primordial rows only if the required parameters are derived without Planck/DESI/Pantheon target data.

Planck’s final cosmological-parameter papers are excellent observational constraints, but they are not a derivation source for a new theory’s (\Omega_m), (n_s), (A_s), or (\Lambda) unless those values emerge independently. ([A&A

][16]) DESI Y1 BAO results are likewise observational distance/expansion constraints, not free calibration data for a strict theory row. ([DESI][17])
