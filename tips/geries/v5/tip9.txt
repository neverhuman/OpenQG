## 1. What the problem is really asking

The brief is not asking for a poetic theory of everything. It is asking for a **derivation-first, leakage-proof OpenQG prediction artifact**.

The true task is:

> Given a proposed law of nature, determine which OpenQG rows can be emitted as `predicted` with value, uncertainty, unit, provenance, and zero calibration data, and which rows must be refused because the law does not determine their constants, state, or estimator pipeline.

The previous agents mostly found the right safety lesson:

```text
ligogr_*       -> 0, if true GR-deviation/null rows
microscope_*   -> 0
sme_*          -> 0, only if true Lorentz/CPT coefficient or null-deviation rows
everything else -> not_implemented
```

But they assumed too quickly that a framework plus equations equals prediction. It does not. A Friedmann equation is not a Planck/DESI row. A CKM definition is not CKM angles. A QCD beta function is not a proton mass. A Kerr shadow formula is not an EHT angular diameter. A spectral finite algebra is not automatically a uniqueness theorem.

The missing compression is this:

> **A prediction is a terminally closed dependency graph, not a formula.**

That statement is the real primitive.

## 3. Primitive II: Minimal Chiral-CP Matter Closure

Previous tips often start with:

[

============

\mathbb C \oplus \mathbb H \oplus M_3(\mathbb C)
]

and then say this gives the Standard Model. That is useful, but it bakes in `3`.

TDC-MCC instead starts one step earlier.

Assume the minimal low-energy chiral gauge law has:

[

===

SU(N_c)\times SU(2)_L\times U(1)_Y
]

with one Higgs doublet and one anomaly-checking family:

[

d^c:(\bar N_c,1,Y_d)

[
L:(1,2,Y_L),\quad
e^c:(1,1,Y_e),\quad

]

Gauge-invariant Yukawa slots with Higgs hypercharge (Y_H) require:

[
Y_u=-Y_Q-Y_H,\qquad
Y_d=-Y_Q+Y_H,
]

[
Y_e=Y_H-Y_L,\qquad
Y_N=-Y_L-Y_H=0.
]

So:

[
Y_L=-Y_H.
]

The (SU(2)^2U(1)) anomaly gives:

[
N_cY_Q+Y_L=0
]

hence:

[
Y_Q=\frac{Y_H}{N_c}.
]

Normalize electromagnetism by requiring the lepton doublet to contain a neutral state and a charge-minus-one state:

[
Q_{\rm em}=T_3+Y,\qquad Y_H=\frac12.
]

Then:

[
Y_Q=\frac{1}{2N_c},
]

[
Y_u=-\frac{N_c+1}{2N_c},
\qquad
Y_d=\frac{N_c-1}{2N_c},
]

[
Y_L=-\frac12,\qquad
Y_e=1,\qquad
Y_N=0.
]

The local anomalies vanish:

[
SU(N_c)^2U(1):\quad 2Y_Q+Y_u+Y_d=0,
]

[
{\rm grav}^2U(1):\quad
2N_cY_Q+N_cY_u+N_cY_d+2Y_L+Y_e+Y_N=0,
]

[
U(1)^3:\quad
2N_cY_Q^3+N_cY_u^3+N_cY_d^3+2Y_L^3+Y_e^3+Y_N^3=0.
]

Now impose global (SU(2)) Witten-anomaly closure. With (N_g) generations, the number of left-handed weak doublets is:

[
N_g(N_c+1).
]

The first generation count allowing a physical CKM-type CP phase is:

[
N_{\rm CP}
==========

\frac{(N_g-1)(N_g-2)}{2}.
]

For (N_g=1) or (2), this is zero. The minimal charged-current theory with intrinsic weak CP capability has:

[
\boxed{N_g=3}.
]

Then Witten closure requires:

[
3(N_c+1)\ \text{even}
]

so (N_c) must be odd. The smallest nonabelian color group with a complex fundamental is:

[
\boxed{N_c=3}.
]

Substitute (N_c=3):

[
Y_Q=\frac16,\quad
Y_u=-\frac23,\quad
Y_d=\frac13,\quad
Y_L=-\frac12,\quad
Y_e=1,\quad
Y_N=0.
]

The electric charges become:

[
\boxed{
Q_u=\frac23,\quad
Q_d=-\frac13,\quad
Q_e=-1,\quad
Q_\nu=0
}
]

and the low-energy gauge skeleton is:

[
\boxed{
G_{\rm SM}
==========

\frac{
SU(3)_c\times SU(2)_L\times U(1)_Y
}{\mathbb Z_6}
}
]

This is a genuine structural derivation, but only under the stated closure premise:

> minimal anomaly-clean chiral matter + vectorlike electromagnetism + minimal intrinsic weak CP capability.

It does **not** derive Yukawa eigenvalues, CKM angles, PMNS angles, neutrino masses, baryon asymmetry, or any hard dimensionless constants.
