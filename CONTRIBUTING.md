# Contributing

1. Read `AGENTS.md`, `agent/JANKURAI_STANDARD.md`, and `agent/MASTER_PLAN.md`.
2. Make the smallest change that proves the intended behavior.
3. Prefer manifest edits over ad hoc scripts.
4. Add or update tests when changing validation or scoring rules.
5. Run the validation lanes that match the scope of the change.

If a change touches generated artifacts, note the source command in the commit message or handoff.
