# Mission

OpenQG exists to turn physics speculation into a benchmarked, inspectable workflow.

The project is trying to answer one narrow question:

> Which candidate theory families can reproduce the public low-energy data better than the SM+GR+LambdaCDM baseline while staying interpretable?

What this is not:

- not a claim that quantum gravity has been solved
- not a black-box model zoo
- not a place for raw data dumps or undocumented fit knobs
