# Theory Admission

To be admitted as a candidate, a theory manifest must provide:

- a stable id and name
- a benchmark suite target
- citations
- a list of observables
- a list of named parameters
- an adapter command that can be executed by the benchmark tooling

Every parameter must carry:

- name
- symbol
- unit
- physical meaning
- prior or fixed value
- reason the value is fixed or free

Candidates that read like gray-box optimizers do not get promoted.
