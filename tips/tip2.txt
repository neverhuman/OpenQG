## Bottom line

The strongest evidence-tested “theory” today is still **Standard Model + general relativity + ΛCDM as an effective low-energy description**, not a completed unification. Planck’s final cosmology analysis found the six-parameter ΛCDM model to be an excellent fit to CMB data, while newer DESI DR2 results add tension by hinting that dark energy may evolve rather than remain a pure cosmological constant; gravitational-wave catalogs and DESI growth measurements continue to test GR in strong-field and cosmic regimes. ([arXiv][1])

My best current bet is not a radically new “one equation” replacement. It is a **constrained hybrid**: keep the observed SM+GR+ΛCDM limit exactly, use **spectral geometry** to explain the SM gauge/Higgs structure, use **asymptotic safety / RG fixed points** for UV predictivity, and use a **causal Lorentzian microstructure** as the regulator so the theory does not become an unconstrained gray-box fit.

I call the proposed model below **Causal–Spectral Asymptotic Unification**, or **CSAU**. It is a concrete testable theory candidate, not an established final theory.

# 3. Proposed theory: Causal–Spectral Asymptotic Unification

## 3.1 Core idea

**CSAU = spectral geometry for matter + asymptotic safety for UV predictivity + causal Lorentzian microstructure for non-gray-box regularization.**

The theory has three postulates:

**Postulate A — Spectral matter geometry.**
The observed SM gauge/Higgs/fermion content is the low-energy inner fluctuation of a finite noncommutative geometry.

**Postulate B — Asymptotic UV completion.**
All dimensionless couplings approach a finite UV fixed point. Only finitely many relevant directions remain free.

**Postulate C — Causal regulator.**
At distances near a physical scale (\ell_*), spacetime is not a Euclidean lattice but a Lorentzian causal structure. The continuum manifold appears as the large-scale limit.

This model is designed to avoid gray-box fitting: every parameter is a mass, coupling, mixing angle, vacuum density, causal discreteness length, or symmetry-breaking scale.

---

## 3.2 Kinematics

At accessible scales, the continuum limit is a 4D Lorentzian spin manifold:

[
(M,g_{\mu\nu},e^a_{\mu},\omega_{\mu}^{ab})
]

with internal spectral algebra

[
\mathcal A_F=\mathbb C\oplus \mathbb H\oplus M_3(\mathbb C).
]

The full algebra is

[
\mathcal A=C^\infty(M)\otimes \mathcal A_F.
]

The Hilbert space is

[
\mathcal H=L^2(M,S)\otimes \mathcal H_F,
]

where (\mathcal H_F) contains three generations of quarks, leptons, antiparticles, and right-handed neutrinos.

The bare Dirac operator is

[
D_0=\slashed{\nabla}\otimes 1+\gamma^5\otimes D_F,
]

where (D_F) encodes Yukawa matrices, Majorana neutrino masses, and flavor mixing.

Gauge and Higgs fields arise from inner fluctuations:

[
D_A=D_0+A+J A J^{-1},
]

[
A=\sum_i a_i[D_0,b_i], \qquad a_i,b_i\in \mathcal A.
]

The resulting low-energy gauge group is

[
G_{\rm SM}=\frac{U(1)_Y\times SU(2)_L\times SU(3)_c}{\Gamma},
]

with the Higgs field appearing as a finite-direction gauge connection rather than an arbitrary scalar added by hand.

## 3.3 Compact action

The complete bosonic action is a spectral action plus a Lorentzian causal regulator:

[
S_{\rm bos}=\operatorname{Tr}, f!\left(\frac{D_A^2}{\Lambda_s^2}\right)+S_{\rm causal}[M,\prec,\ell_*],
]

and the fermion action is

[
S_{\rm ferm}=\langle \Psi, D_A\Psi\rangle.
]

Here:

* (\Lambda_s) = spectral unification scale.
* (f) = cutoff/profile function; its low moments correspond to physical vacuum, gravitational, and gauge normalizations.
* (\ell_*) = causal discreteness length, expected near the Planck length unless data demand otherwise.
* (\prec) = causal order relation.

The spectral expansion gives

[
\operatorname{Tr} f(D_A^2/\Lambda_s^2)
\sim
\sum_{n\ge 0} f_{4-n}\Lambda_s^{4-n}a_n(D_A^2),
]

where (a_n) are heat-kernel coefficients.

## 3.5 UV completion condition

Define dimensionless couplings

[
\tilde g_i(k)=k^{-d_i}g_i(k),
]

where (d_i) is the mass dimension of coupling (g_i). The RG flow is

[
\frac{d\tilde g_i}{d\ln k}=\beta_i(\tilde g_1,\tilde g_2,\ldots).

CSAU requires a UV fixed point:

[
\beta_i(\tilde g^*)=0,
]

with finite relevant directions determined by the stability matrix

[
B_{ij}
======

\left.
\frac{\partial \beta_i}{\partial \tilde g_j}
\right|_{\tilde g=\tilde g^*}.

The critical exponents are

[
\theta_I=-{\rm eig}(B).
]

Only directions with (\theta_I>0) are free physical inputs. All irrelevant couplings are predictions:

[
\tilde g_i(k)
=============

\tilde g_i^*
+
\sum_{I\in{\rm relevant}}
C_I V_i^{(I)}
\left(\frac{k}{M_*}\right)^{-\theta_I}.
]

This is where the theory avoids a gray-box parameter explosion.

\Box\phi

This gives a Lorentzian UV regulator without putting the universe on a preferred-frame spatial lattice.

# 4. Error metric for testing theories

For a theory (T) with physical parameter vector (\theta_T), define the total likelihood

[
\ln \mathcal L_T(\theta_T)
==========================

\sum_b
\ln \mathcal L_b
\left[
d_b\mid \mu_b(\theta_T),C_b
\right],
]

where (b) indexes data blocks: collider, neutrino, CMB, BAO, SN, weak lensing, GW, solar-system, dark matter, atomic/nuclear, etc.

For Gaussian blocks:

[
\chi_b^2
========

\left(d_b-\mu_b(\theta_T)\right)^T
C_b^{-1}
\left(d_b-\mu_b(\theta_T)\right).
]

Total fit error:

[
\chi^2_{\rm tot}(T)
===================

\sum_b \chi_b^2.
]

Model comparison should not reward extra parameters unless they earn their keep:

[
{\rm AICc}
==========

\chi^2_{\rm min}
+
2k
+
\frac{2k(k+1)}{N-k-1},
]

[
{\rm BIC}
=========

\chi^2_{\rm min}
+
k\ln N,
]

[
Z_T
===

\int d\theta_T,
\mathcal L_T(\theta_T)\pi_T(\theta_T),
]

[
\ln B_{T,T_0}
=============

\ln Z_T-\ln Z_{T_0}.
]

Here (T_0) is the baseline SM + GR + ΛCDM model.

To enforce your “no gray box” rule, add a transparency penalty:

[
\mathcal S_T
============

-2\ln Z_T
+
\lambda_{\rm gray}N_{\rm gray}
+
\lambda_{\rm fail}N_{\rm hard\ fail}.
]

A parameter counts as gray if it lacks one of these:

[
\text{physical unit, operational measurement, symmetry role, or limiting-case interpretation.}
]

For CSAU, the target is

[
N_{\rm gray}=0.
]

# 6. How I would test CSAU first

The first benchmark should be nested against the empirical baseline:

[
T_0 = {\rm SM}+{\rm GR}+\Lambda{\rm CDM}.
]

Then test CSAU in four layers.

### Layer 1 — Particle physics

Use PDG + HEPData + CERN Open Data.

Fit:

[
{g_1,g_2,g_3,v,\lambda_H,Y_f,V_{\rm CKM},U_{\rm PMNS},M_N}.
]

Reject if collider or precision data require nonphysical parameter choices.

### Layer 2 — Cosmology

Use Planck + ACT + SPT + DESI DR2 + Pantheon+ + DES.

Compare:

[
\Lambda{\rm CDM}
\quad \text{vs.} \quad
\Lambda{\rm CDM}+Q
\quad \text{vs.} \quad
{\rm CSAU}.
]

The dark-energy likelihood should decide whether (Q) is active.

### Layer 3 — Gravity

Use GWOSC/GWTC-4, LLR, JPL ephemerides, MICROSCOPE, Eöt-Wash.

Constrain:

[
m_g,\quad \beta_4,\quad \beta_6,\quad M_*,\quad \dot G/G,\quad \eta_{\rm WEP}.
]

### Layer 4 — Dark matter

Use XENON, COSINE/DMDC, LZ constraints, CMB, Gaia, clusters, dwarf galaxies, and lensing.

Fit:

[
f_a,\quad m_a,\quad \theta_i,\quad C_\gamma
]

and check consistency with cosmological dark-matter abundance.
