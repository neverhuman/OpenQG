## 11. Adapter policy

The adapter must behave like a theorem checker, not a predictor engine.

Algorithm:

1. Read fixture row ID, domain, unit, and non-value metadata.
2. Do **not** read target value, benchmark feedback, reference predictor output, or validation source value for prediction logic.
3. Classify row shape:

   * exact null/deviation coefficient,
   * metrology/dimensionless constant,
   * particle/property table,
   * source-state catalog,
   * empirical summary parameter,
   * ambiguous normalized bin.
4. Emit `predicted` only if the row is one of:

   * `ligogr_*` true GR deviation/null residual,
   * `microscope_*` Eötvös/WEP violation parameter,
   * `sme_*` SME coefficient/null-deviation row.
5. Otherwise emit `not_implemented` with a specific refusal reason.
6. If shape is ambiguous, refuse.
7. Preserve unit only for formatting zero; do not use row value.
8. Emit exactly one row per fixture observable.

This policy prevents the most dangerous leakage path: using a row’s family label as a license to infer a hidden measured value.
