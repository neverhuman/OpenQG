## Core finding

All eleven drafts are trying to solve the same thing: **produce a derivation-first OpenQG “unified theory” dossier that clears the brief’s 85/100 pre-submission gate without cheating on benchmark fixtures.**

The best drafts correctly understand the brief’s central rule: **unsupported rows are acceptable; dishonest numeric rows are fatal.** The weak drafts then over-score themselves by treating “I wrote a plausible framework and refused the hard rows” as almost equivalent to “I derived the required domains.”

My final judgment: **none of the over-85 claims in the archive is honestly justified as written.** The strongest answer is a conservative synthesis of the spectral/asymptotic-safety candidates plus the law/state discipline from KSEG, but it should be scored **below 85** until the missing derivations or an actual adapter/source-pack audit exist.

# What the brief is really demanding

`unified-theory-agent-brief.v2.md` is not asking for a nice-sounding theory. It is asking for a **runnable, auditable prediction artifact**.

The key requirements are:

1. **Derivation before code.**
   Every predicted row must be mathematically derivable before adapter implementation.

2. **No fixture leakage.**
   No target values, validation source IDs, reference predictors, benchmark feedback, fitted regressors, copied constants, or row-wise memorization.

3. **Constants ledger.**
   The theory must distinguish SI/metrology anchors from true dimensionless physical targets, structural integers, free parameters, and unsupported quantities.

4. **One row per observable.**
   Every fixture row must be emitted as `predicted`, `not_implemented`, or `invalid_domain`.

5. **Unsupported rows are okay.**
   A refusal is better than fake numerics.

6. **The scorecard is not the benchmark score.**
   A pre-submission score can be high while the actual non-empirical theory coverage remains low.

That last point is where many drafts become slippery: they claim **86–88/100 dossier scores** while admitting their actual fixture coverage is basically the same narrow null-row coverage as the baseline.

# Where they are weak

The recurring weakness is **score inflation**.

Most high-score drafts do this:

> “We have equations or a framework for every domain, and we refuse unsupported rows, therefore the dossier is 86–88/100.”

That is too generous. The brief’s mathematical-derivation category is not just asking for a gesture at each domain. It asks for equations, assumptions, parameter origins, dimensional analysis, limiting cases, source provenance, fixture mapping, uncertainty propagation, and executable metadata. For many hard domains, the drafts mostly say: “not solved yet.”

That is honest, but it should cost more points.

Major weaknesses:

| Weakness                                   | Why it matters                                                                                                                                       |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No real derivation of (\alpha)**         | CODATA/fine-structure rows cannot be predicted without deriving or independently reproducing (\alpha).                                               |
| **No Yukawa/mass derivation**              | PDG, HEPData, flavor, CKM, PMNS, and neutrino rows remain unsupported.                                                                               |
| **No Higgs/electroweak-scale derivation**  | (v), Higgs mass, (M_W), (M_Z), and precision electroweak observables are not derived.                                                                |
| **No QCD/hadron solver**                   | (\Lambda_{\rm QCD}), hadron masses, nuclear binding, and atomic nuclear corrections remain unavailable.                                              |
| **No cosmology closure**                   | Vacuum energy, dark matter abundance, baryon asymmetry, (A_s), (n_s), (H_0), (\Omega_i), BAO, CMB, and supernova mappings remain mostly unsupported. |
| **No galaxy-dynamics closure**             | SPARC rows need baryonic profiles plus a dark-sector or modified-gravity rule.                                                                       |
| **No independent state-provenance system** | GWOSC, EHT, JPL, SPARC, and Pantheon rows depend on historical source states.                                                                        |
| **No executable adapter or run evidence**  | Most drafts provide plans, not tested artifacts.                                                                                                     |
| **Invented selector terms are not solved** | “spectral torsion,” “trace-anomaly bootstrap,” “generation index,” and similar additions sound promising but are not demonstrated.                   |
| **SME row-shape ambiguity**                | Predicting zero SME coefficients is valid only if the fixture row is a coefficient/deviation row, not merely an experimental upper-bound magnitude.  |

# What they are missing

The missing piece is not more rhetoric. It is a **law/state/provenance architecture**.

The brief should require, and the final theory should include:

1. **A law ledger**
   What the theory derives universally: symmetries, gauge group, null deviations, anomaly cancellation, structural integers.

2. **A constants ledger**
   What is derived, assumed, metrological, free, or unsupported.

3. **A state ledger**
   Independent non-target inputs for object-specific quantities: binary masses, black-hole distances, galaxy baryon profiles, solar-system initial conditions, supernova redshifts, etc.

4. **A row-shape validator**
   The adapter must distinguish “coefficient value,” “upper bound,” “catalog state,” “distance modulus,” “normalized bin,” and “structural target.”

5. **A scoring cap rule**
   A candidate with no derivation of (\alpha), Yukawas, flavor matrices, vacuum energy, dark matter, primordial parameters, and mass ratios should not score above 85 merely because it refuses those rows.

A useful cap would be:

| Missing item                          |                                                                                  Suggested cap |
| ------------------------------------- | ---------------------------------------------------------------------------------------------: |
| No executable adapter/run             |                                                                                         max 82 |
| No derived dimensionless constants    |                                                                                         max 82 |
| No particle/flavor numeric derivation |                                                                                         max 80 |
| No cosmology/dark-sector closure      |                                                                                         max 80 |
| No law/state provenance protocol      |                                                                                         max 78 |
| Only null-row predictions             | max 80, unless the brief explicitly rewards dossier quality independent of predictive coverage |
